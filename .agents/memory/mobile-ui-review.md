---
name: Mobile UI review expectations
description: User's repeated requirement to check signed-in mobile usability, not just the login screen.
---

**Rule:** Check the mobile app's signed-in UI/UX, including citizen hero-button readability and back navigation on tabs and secondary screens. A working login preview is not enough.

**Why:** The user repeatedly requested UI/UX checks and reported unreadable white hero buttons and missing back options after earlier checks.

**How to apply:** Review shared controls and actual account screens when fixing mobile UI. Distinguish code checks from browser or native-device verification; do not claim untested screens were checked.
