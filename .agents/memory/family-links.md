---
name: Cross-constituency family links
description: Product and privacy rules for linking family members across constituency transfers.
---

Use the global Person relationship graph so active family links remain visible when either person changes constituency. Each person's account, household, issue records, and service history remain in their own constituency. A cross-constituency link requires the recipient's acceptance and exposes only basic contact, relationship, and constituency details. Ending a link removes it for both people.

**Why:** The user approved cross-constituency family links while keeping each person's account in their own constituency.

**How to apply:** Do not move relatives or household/service records during an account transfer. Keep relationship lookup on stable Person IDs, require consent before creating a cross-tenant link, return minimal family data, and revoke the shared relationship for both accounts when either side removes it.
